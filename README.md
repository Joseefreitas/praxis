# Práxis

## Sobre o projeto 
**Práxis** é uma ferramenta de suporte ao uso de **IA (Inteligência Artificial)** para estudantes do ensino médio que planejam fazer a prova do ENEM. Práxis ensina as boas práticas do uso de ferramentas de **IA** devolvendo a autonomia dos estudantes sobre a ferramenta.

## Como Executar Localmente

```bash
git clone https://github.com/Joseefreitas/praxis.git
cd praxis

python -m venv .venv
source venv/bin/activate  # Linux/Mac
venv\Scripts\activate     # Windows

pip install -r requirements.txt
```
``
